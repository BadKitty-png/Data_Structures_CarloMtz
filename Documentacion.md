# Documentacion
---
Esta es la documentación que se buscara a lo largo del proyecto, como primer paso 
el codígo para configurar el usuario y cuenta de forma global
```console
    git config user.name "BadKitty-png"
    git config user.email "1225100330.jcm@gmail.com"
```
Para agregar un destino es con el siguiente condigo 

```console 
    git remote set url origin <URL DESTINO SSH O HTTPS>
```

Verificar destino, este te dara las dos rutas actuales

```console 
    git remote -v
```
